# Computational Discovery Field Guide

Live site: <https://miyu-horiuchi.github.io/drug-discovery-model-landscape/>

From the repository root:

```bash
python3 -m http.server 8000 --directory drug-discovery-model-landscape
```

Open <http://localhost:8000>. Stop the server with `Ctrl+C`.

The page has no build step or external runtime dependency. Use the top-level tabs to switch between the drug-discovery model stack and ML interatomic potentials. The percentage figures are evidence signals with explicit labels and populations, not market-share slices. The atom animations are explanatory abstractions rather than numerical simulations.
